## General

**What is EZCommerse?**  
A business management platform for restaurant owners covering POS, inventory, CRM, expenses, and reporting.

**Is there a live demo?**  
Yes: [https://www.ezcommerse.com/](https://www.ezcommerse.com/)

**What license is it under?**  
[MIT](../LICENSE).

## Self-hosting

**What do I need to run it locally?**  
Node.js 22+, npm, and PostgreSQL (or Docker Compose for the API + database).

**Where do environment variables live?**  
Copy `be/.env.example` → `be/.env` and `webFe/.env.example` → `webFe/.env`.
