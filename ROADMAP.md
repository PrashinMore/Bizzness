# Roadmap

High-level plans for EZCommerse. Items here are directional, not commitments.

## Near term

- [ ] Stabilize CI (lint + unit tests) on every PR
- [ ] Expand automated coverage for sales and inventory flows
- [ ] Publish contributor onboarding docs with a recorded demo walkthrough
- [ ] Add a real product screenshot / GIF to the README

## Medium term

- [ ] Harden production deployment docs (Docker, env vars, reverse proxy)
- [ ] Improve offline / sync story for the mobile companion app
- [ ] Community Discord / Discussions launch
- [ ] Internationalization (i18n) for the web UI

## Longer term

- [ ] Plugin / extension points for custom POS workflows
- [ ] Multi-language documentation
- [ ] Formal security audit checklist for self-hosters

Suggestions welcome via [GitHub Issues](https://github.com/PrashinMore/Bizzness/issues) with the `enhancement` label.
